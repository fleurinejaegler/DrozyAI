WHAT’S BEHIND THE READING

Watch and video models, together.

The saved gradient boosting watch model and small video TCN now drive the model score. When both have fresh, aligned windows, their 50/50 average drives the main gauge and watch alert; the local AI advisor explains the result without changing the score or action. Partial video windows remain visible as provisional outputs. Because the trained model can return spurious high scores with missing frames, partial video is excluded from the main score and alerts; full eligible watch/video scores are averaged. Missing sources remain unavailable. Live RGB geometry and Garmin sensor transfer are experimental. Temperature uses the last real value when a packet returns null; motion variance uses the last measured value for gaps up to five seconds; genuine beat intervals are never inferred from heart rate.

View prototype rules and limitations +

Eye closure is estimated from face-model expression scores, using a threshold of 0.55. This is an eye-closure proxy, not a validated PERCLOS measurement. A completed closure of 80–800 ms counts as a blink. The rolling fraction uses up to 60 seconds of valid observed time and needs at least 15 seconds and 80% tracking coverage.

The main gauge shows the saved models’ uncalibrated score from 0 to 100. Live alerts use 70 for a break after three consecutive model updates, and 90 for stopping safely. These thresholds and device transfer need validation; the score is not a percentage chance of drowsiness. Missing or stale model windows never imply low drowsiness.

Heart rate comes from Bluetooth Heart Rate Measurement notifications. Genuine intervals and motion come separately from the Connect IQ app; none are inferred from BPM. The trend comparison uses the first available 30-second portion of the displayed history; it is descriptive and does not establish drowsiness.

Face landmarks: Google MediaPipe. Bluetooth bridge: Bleak. Camera frames remain in browser memory; only numeric geometry/event features are sent to the local model server. Feature files selected in the model test are sent only to the GX10 through the SSH connection, used in memory and not saved.
